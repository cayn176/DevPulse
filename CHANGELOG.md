# Releases

## 0.3.0 — Pulse Relay

Introduces a geometric DevPulse mark, graphite and paper themes, persistent system theme selection, teal and steel accents, responsive layouts and keyboard focus handling for dialogs. The overview includes workspace signals. Tasks now carry due dates, labels and a local change history. Projects have an inspector for metadata, associated sessions and tasks. The activity ledger combines project, agent, workflow, task and deployment events.

The Windows release includes a small internet installer and a standalone offline installer. The bootstrap downloads the exact release package and checks its SHA-512 digest. The desktop API uses the official Windows Python executable.

## 0.2.0

Introduced the local desktop workspace, native coding-agent adapters, project editor, Git operations, GitHub repository assistant, tasks and workflows, deploy management and browser preview.
